# Coppify backend dependencies

# Install with:  pip install -r backend/requirements.txt
#
# FFmpeg is a native binary, not a pip package. The backend finds it via
# $FFMPEG_BINARY -> $PATH -> the static build bundled by imageio-ffmpeg, and
# creates a `.bin/ffmpeg.exe` shim so openai-whisper (which shells out to a
# bare `ffmpeg`) can find it too. Install imageio-ffmpeg and you never need to
# touch a system FFmpeg install.
